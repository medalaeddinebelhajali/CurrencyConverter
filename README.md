## 1. Présentation du projet

**Currency Converter** est une application Android développée en Kotlin permettant de convertir un montant d'une devise vers une autre à l'aide de taux de change fixes.



L'application prend en charge les devises suivantes :

| Devise | Code | Taux pour 1 EUR |
|---|---|---:|
| Euro | EUR | 1.00 |
| Dollar américain | USD | 1.17 |
| Dinar tunisien | TND | 3.40 |
| Livre sterling | GBP | 0.87 |
| Yen japonais | JPY | 172.50 |
| Dollar canadien | CAD | 1.62 |
